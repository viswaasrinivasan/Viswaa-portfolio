The Story

Curiosity is a security skill.

I’m a first-year CSE (Cybersecurity) student at Sathyabama, focused on the fundamentals that make systems hard to break: how networks communicate, how software fails, and how attackers think about both. The through-line is simple: find the weak point most people overlook, understand it well enough to test it safely, and help fix it before someone else finds it.

  • 01

    Think like an attacker

    Defense starts with knowing how a system can be abused. I study offensive techniques so I can spot weak points before they are exploited.

  • 02

    Ethics before exploits

    I practice in legal labs, capture-the-flag challenges, and systems I am authorized to test. Skill without judgment is a liability.

  • 03

    Fundamentals compound

    Networking, operating systems, and cryptography take time to learn and last for decades. I would rather know the basics deeply than chase every new tool.

  • 04

    Write it up clearly

    Findings only matter if people can act on them. I document what I learn so the next person does not have to rediscover it.
